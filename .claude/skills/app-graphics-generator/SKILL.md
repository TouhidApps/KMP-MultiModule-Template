# App Logo, Icons and Brand Graphics

One small vector file, `branding/logo/mark.svg`, is the source of the logo and of
**every** icon the app ships. A script renders all platform sizes from it, for
PROD and for UAT (UAT gets a "UAT" badge). Nothing is drawn twice by hand, and
nothing is downloaded.

Reference:
[TouhidApps/KMP-MultiModule-Template](https://github.com/TouhidApps/KMP-MultiModule-Template)
(Amper, `app/androidApp`, `app/iosApp`, `core/ui` owns all drawables through
`Resources.Drawable`). Related skills:
- `compose-multiplatform-ui` 2.0.1 (copyright rules) and 2.0.2 (in-app icons,
  illustrations, backgrounds). This skill reuses those rules and does not repeat them.
- `kmp-environments` (UAT vs PROD, `scripts/use_env.py`, "(UAT)" launcher name).
- `store-assets-generator` (store screenshots and feature graphic; it uses the
  icons made here).

## 1. Copyright and originality (non-negotiable)

Everything in `compose-multiplatform-ui` 2.0.1 applies. For brand graphics in particular:
- **Draw the logo yourself** as simple geometric vector paths. Never trace, copy,
  "remix" or imitate an existing logo, app icon, mascot, game or brand, and never
  use an image search, stock site or AI image from an unknown source as input.
- **No third-party marks** in the icon: no Android robot, Apple logo, Material
  "M", Google colors pattern, flags of other products, or store badges.
- **Material Symbols** (Apache 2.0) may be used as a *starting shape* for a mark
  only if it is changed into something distinctive. A bare stock icon is a weak,
  non-unique app icon. Say which symbol was used.
- **Wordmark text** uses an OFL/Apache font already in
  `core/ui/composeResources/font/`. Convert it to paths (section 7). OFL allows
  this for artwork.
- If the user supplies their own logo, use it and don't redesign it. Convert it
  to the `mark.svg` rules (section 3) and keep the colors.
- Tell the user that the generated logo is original work, but that **you cannot
  run a trademark search**. Before launch they should search the name and mark
  in their markets (e.g. WIPO Global Brand Database, USPTO, their national office).

## 2. Layout

```
branding/

  logo/
    mark.svg                       # committed: THE source, 108x108 canvas, plain paths
    lockup.svg                     # committed: mark + wordmark, for web/press (optional)
  concepts/                        # committed: concept sheets shown to the user (not shipped)
  generated/                       # committed, GENERATED by make_icons.py — never hand-edit
    prod/  android/res/...  ios/AppIcon.appiconset/  store/play-icon-512.png  web/
    uat/   (same, with the UAT badge)
scripts/branding/
  make_icons.py                    # mark.svg + brand.json -> generated/{prod,uat} + in-app logo
core/ui/composeResources/drawable/
  app_logo.xml                     # GENERATED in-app logo (tile + mark), via Resources.Drawable.AppLogo
app/androidApp/res/                # active env's icon, COPIED by scripts/use_env.py
app/iosApp/.../Assets.xcassets/AppIcon.appiconset/   # active env's icon, COPIED by use_env.py
```

`brand.json`:
```json
{
  "appName": "KMP Template",
  "seedColor": "#3D5AFE",
  "background": { "start": "#3D5AFE", "end": "#1A237E" },
  "darkBackground": "#121318",
  "foreground": "branding/logo/mark.svg",
  "storeCrop": 88,
  "androidMinSdk": 24,
  "uatBadge": { "fill": "#FFB300", "text": "#1F1F1F" }
}
```
- `seedColor` is the **same seed** as the Material 3 theme in `core/ui`
  (`compose-multiplatform-ui` 2.1). Icon and app always match. When one changes,
  change both.
- `background.start/end` are two tones of the seed (or `start == end` for a flat color).
- `storeCrop` is the part of the 108 canvas used for square icons (iOS, Play,
  web). 88 gives the mark about 55% of the icon, close to Apple's and Google's
  keylines.
- `androidMinSdk` comes from `app/androidApp/module.yaml`. Legacy PNGs are
  generated only when it is below 26.
- Find the iOS asset catalog with `find app/iosApp -name '*.xcassets'`. If there
  is none, create `app/iosApp/src/Assets.xcassets/` with a root `Contents.json`
  (`{"info":{"author":"xcode","version":1}}`) and check that the iOS build picks
  it up. Don't guess another path.

## 3. The source mark: `mark.svg` rules

The mark is drawn on the **Android adaptive icon canvas** (108×108). Every other
size is cut from it, so these rules make every platform come out right:

| Zone (on 108×108) | Meaning |
|---|---|
| whole 108×108 | adaptive foreground layer. Launchers move and scale it (parallax) |
| center 72×72 (18..90) | the most a launcher mask ever shows |
| center circle, Ø 66 | **safe zone**: never cut by any mask (circle, squircle, teardrop) |
| center 48×48 (30..78) | **put the mark here**. Leaves room for masks and the UAT badge |
| y 70..82, x 39..69 | reserved for the UAT pill (the mark may run under it) |

Allowed content, so the script can convert it to an Android vector with no loss:
- `viewBox="0 0 108 108"`, then only `<path d="…" fill="#RRGGBB">` with optional
  `fill-opacity` and `fill-rule="evenodd"`.
- **No** strokes (outline them), transforms (apply them), `<text>` (convert to
  paths), gradients, filters, masks, embedded bitmaps, `<use>` or CSS. The
  script rejects them.
- The foreground has **no background**. The background is `brand.json`'s gradient.
- 1–3 fill colors, usually white or a light tint on the brand background. Use
  opacity steps (1.0 / 0.75 / 0.5) of one color for depth.

```xml
<!-- branding/logo/mark.svg : original mark, self-drawn -->
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 108 108">
  <path d="M34,40a6,6 0,0 1,6 -6h12v40h-12a6,6 0,0 1,-6 -6z" fill="#FFFFFF"/>
  <path d="M56,34h12a6,6 0,0 1,6 6v10h-18z" fill="#FFFFFF" fill-opacity="0.75"/>
  <path d="M56,54h18v14a6,6 0,0 1,-6 6h-12z" fill="#FFFFFF" fill-opacity="0.5"/>
</svg>
```

## 4. Designing the logo (when the user has none)

1. **Brief.** Get the app name, what the app does in one sentence, the audience,
   and the theme seed color. If the user hasn't said, read them from the project
   (`StringsEn.appName`, the theme seed) and say what you assumed.
2. **Three concepts**, each a different idea, not three colorways:
   - *Symbol*: a simple shape for the app's purpose (a ticket, a leaf, a chat bubble, a calendar tile).
   - *Monogram*: the first letter built from geometric shapes, not typed from a font.
   - *Abstract*: a distinctive geometric construction (e.g. offset tiles,
     a split circle) in the brand colors.
3. **Design rules**:
   - Flat geometric shapes, a 2 dp grid, rounded corners in steps of 2/4/6, and
     no detail smaller than 4 dp (it disappears at 48 px).
   - At most 2 colors plus opacity steps. It must also work as **one solid
     color** (Android themed icon, iOS tinted icon, monochrome).
   - No text in the icon apart from a 1-letter monogram. App names are illegible
     at launcher size, and the store shows the name anyway.
   - It must not look like a well-known mark. If a concept reminds you of an
     existing brand, drop it.
4. **Concept sheet.** Render each concept with `make_icons.py`'s
   `svg_doc` + `png` helpers at 1024, 180, 96 and 48 px, on light and dark
   wallpapers, with circle and rounded-square masks, into
   `branding/concepts/<n>-<name>.png`. Show the sheets to the user.
5. **The user picks.** Picking a logo changes the product's identity, so ask with
   one decision card (three concepts, recommend one, say why). Meanwhile, build
   with the recommended one so everything else can move on. Swapping later is
   a one-file change.
6. Save the chosen concept as `branding/logo/mark.svg` and run section 5.

## 5. Generate every icon: `scripts/branding/make_icons.py`

```bash
pip install cairosvg pillow          # macOS: brew install cairo first
python3 scripts/branding/make_icons.py
python3 scripts/use_env.py uat       # copies the active env's icon into the app (section 6)
```

It writes, for **prod** and **uat**:

| Output | Spec |
|---|---|
| `android/res/drawable/ic_launcher_background.xml` | vector, 108 dp, linear gradient (`aapt:attr`) |
| `android/res/drawable/ic_launcher_foreground.xml` | vector from `mark.svg` (+ UAT pill) |
| `android/res/drawable/ic_launcher_monochrome.xml` | one-color layer for Android 13+ themed icons |
| `android/res/mipmap-anydpi-v26/ic_launcher(_round).xml` | `<adaptive-icon>` with all three layers |
| `android/res/mipmap-<density>/ic_launcher(_round).png` | 48–192 px legacy icons, only if minSdk < 26 |
| `ios/AppIcon.appiconset/` | single-size 1024×1024 PNG, **no alpha**, square (iOS rounds it), plus dark and tinted variants and `Contents.json` |
| `ios/LaunchLogo.imageset`, `ios/LaunchBackground.colorset` | iOS launch screen mark (120 pt, 1x/2x/3x) and brand color (section 8) |
| `store/play-icon-512.png` | 512×512 32-bit PNG, full square (Play applies the mask and shadow) |
| `web/` | favicon 32, PWA 192/512, apple-touch-icon 180 (no alpha) |
| `core/ui/composeResources/drawable/app_logo.xml` | in-app logo (PROD only, never badged), flat color |

```python
#!/usr/bin/env python3
"""Generates every app icon from branding/brand.json + branding/logo/mark.svg.

Writes branding/generated/<env>/ for env in (prod, uat) and the in-app logo.
Usage: python3 scripts/branding/make_icons.py
Needs: pip install cairosvg pillow
"""
import io
import json
import re
import shutil
import xml.etree.ElementTree as ET
from pathlib import Path

import cairosvg
from PIL import Image

ROOT = Path(__file__).resolve().parents[2]
BRAND = json.loads((ROOT / "branding/brand.json").read_text())
OUT = ROOT / "branding/generated"
IN_APP_LOGO = ROOT / "core/ui/composeResources/drawable/app_logo.xml"

CANVAS = 108                      # adaptive icon canvas (dp)
VISIBLE = 72                      # what a launcher mask can show
LEGACY_SIZES = {"mdpi": 48, "hdpi": 72, "xhdpi": 96, "xxhdpi": 144, "xxxhdpi": 192}
SVG_NS = "{http://www.w3.org/2000/svg}"

# "UAT" pill: inside the 66dp safe circle, letters drawn as blocky paths (no font needed).
UAT_PILL = "M45,70h18a6,6 0,0 1,0 12h-18a6,6 0,0 1,0 -12z"
UAT_TEXT = ("M45,73h1.6v4.4h1.8v-4.4h1.6v6h-5z "                       # U
            "M51.5,79v-6h5v6h-1.6v-2h-1.8v2z M53.1,74.6v1h1.8v-1z "    # A (with counter)
            "M58,73h5v1.6h-1.7v4.4h-1.6v-4.4h-1.7z")                   # T


def read_mark(svg_path):
    """Returns the mark's paths. The SVG may contain only <path d fill [fill-opacity] [fill-rule]>."""
    tree = ET.parse(svg_path).getroot()
    if tree.get("viewBox") != f"0 0 {CANVAS} {CANVAS}":
        raise SystemExit(f"{svg_path}: viewBox must be '0 0 {CANVAS} {CANVAS}'")
    paths = []
    for el in tree.iter():
        tag = el.tag.replace(SVG_NS, "")
        if tag in ("svg", "title", "desc"):
            continue
        if tag != "path" or el.get("transform") or el.get("stroke"):
            raise SystemExit(f"{svg_path}: only plain filled <path> elements are allowed, found <{tag}>")
        paths.append({
            "d": el.get("d"),
            "fill": el.get("fill", "#000000"),
            "opacity": float(el.get("fill-opacity", "1")),
            "evenOdd": el.get("fill-rule") == "evenodd",
        })
    return paths


def badge_paths(env):
    if env == "prod":
        return []
    badge = BRAND["uatBadge"]
    return [
        {"d": UAT_PILL, "fill": badge["fill"], "opacity": 1.0, "evenOdd": False},
        {"d": UAT_TEXT, "fill": badge["text"], "opacity": 1.0, "evenOdd": True},
    ]


def argb(hex_color, opacity=1.0):
    return f"#{round(opacity * 255):02X}{hex_color.lstrip('#').upper()}"


def vector_xml(paths, header="", size=CANVAS):
    body = "\n".join(
        f'    <path android:fillColor="{argb(p["fill"], p["opacity"])}"'
        + (' android:fillType="evenOdd"' if p["evenOdd"] else "")
        + f'\n        android:pathData="{p["d"]}"/>'
        for p in paths
    )
    return (f'<?xml version="1.0" encoding="utf-8"?>\n<!-- GENERATED by scripts/branding/make_icons.py -->\n'
            f'<vector xmlns:android="http://schemas.android.com/apk/res/android"{header}\n'
            f'    android:width="{size}dp" android:height="{size}dp"\n'
            f'    android:viewportWidth="{size}" android:viewportHeight="{size}">\n{body}\n</vector>\n')


def background_xml():
    bg = BRAND["background"]
    return f'''<?xml version="1.0" encoding="utf-8"?>
<!-- GENERATED by scripts/branding/make_icons.py -->
<vector xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:aapt="http://schemas.android.com/aapt"
    android:width="{CANVAS}dp" android:height="{CANVAS}dp"
    android:viewportWidth="{CANVAS}" android:viewportHeight="{CANVAS}">
    <path android:pathData="M0,0h{CANVAS}v{CANVAS}h-{CANVAS}z">
        <aapt:attr name="android:fillColor">
            <gradient android:type="linear" android:startX="0" android:startY="0"
                android:endX="{CANVAS}" android:endY="{CANVAS}"
                android:startColor="{argb(bg["start"])}" android:endColor="{argb(bg["end"])}"/>
        </aapt:attr>
    </path>
</vector>
'''


def svg_doc(paths, crop, background="gradient", mask=None):
    """SVG of the icon, cropped to the centered `crop` x `crop` square of the 108 canvas."""
    o = (CANVAS - crop) / 2
    bg = BRAND["background"]
    defs = (f'<linearGradient id="bg" x1="0" y1="0" x2="{CANVAS}" y2="{CANVAS}" gradientUnits="userSpaceOnUse">'
            f'<stop offset="0" stop-color="{bg["start"]}"/><stop offset="1" stop-color="{bg["end"]}"/></linearGradient>')
    if mask == "circle":
        defs += f'<clipPath id="m"><circle cx="54" cy="54" r="{crop / 2}"/></clipPath>'
    elif mask == "rounded":
        defs += f'<clipPath id="m"><rect x="{o}" y="{o}" width="{crop}" height="{crop}" rx="{crop * 0.18}"/></clipPath>'
    fill = {"gradient": "url(#bg)", "none": "none"}.get(background, background)
    shapes = "".join(
        f'<path d="{p["d"]}" fill="{p["fill"]}" fill-opacity="{p["opacity"]}"'
        + (' fill-rule="evenodd"' if p["evenOdd"] else "") + "/>"
        for p in paths
    )
    clip = ' clip-path="url(#m)"' if mask else ""
    return (f'<svg xmlns="http://www.w3.org/2000/svg" viewBox="{o} {o} {crop} {crop}"><defs>{defs}</defs>'
            f'<g{clip}><rect x="0" y="0" width="{CANVAS}" height="{CANVAS}" fill="{fill}"/>{shapes}</g></svg>')


def png(svg, px, path, alpha=True, grayscale=False):
    image = Image.open(io.BytesIO(cairosvg.svg2png(bytestring=svg.encode(), output_width=px, output_height=px)))
    if grayscale:
        image = image.convert("LA").convert("RGBA")
    if not alpha:                                    # App Store and Play feature assets reject alpha
        image = image.convert("RGB")
    path.parent.mkdir(parents=True, exist_ok=True)
    image.save(path, optimize=True)


def white(paths):
    return [{**p, "fill": "#FFFFFF"} for p in paths]


def mono(paths):
    return [{**p, "fill": "#000000", "opacity": 1.0} for p in paths]


def write_android(env, fg, out):
    res = out / "android/res"
    for d in ("drawable", "mipmap-anydpi-v26"):
        (res / d).mkdir(parents=True, exist_ok=True)
    (res / "drawable/ic_launcher_background.xml").write_text(background_xml())
    (res / "drawable/ic_launcher_foreground.xml").write_text(vector_xml(fg + badge_paths(env)))
    # Monochrome layer for Android 13+ themed icons: the badge pill with its letters cut out.
    mono_paths = mono(fg)
    if env != "prod":
        mono_paths.append({"d": f"{UAT_PILL} {UAT_TEXT}", "fill": "#000000", "opacity": 1.0, "evenOdd": True})
    (res / "drawable/ic_launcher_monochrome.xml").write_text(vector_xml(mono_paths))
    adaptive = ('<?xml version="1.0" encoding="utf-8"?>\n'
                '<adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">\n'
                '    <background android:drawable="@drawable/ic_launcher_background"/>\n'
                '    <foreground android:drawable="@drawable/ic_launcher_foreground"/>\n'
                '    <monochrome android:drawable="@drawable/ic_launcher_monochrome"/>\n'
                '</adaptive-icon>\n')
    for name in ("ic_launcher", "ic_launcher_round"):
        (res / f"mipmap-anydpi-v26/{name}.xml").write_text(adaptive)
    if BRAND["androidMinSdk"] < 26:                  # legacy PNGs only for pre-Oreo devices
        for density, px in LEGACY_SIZES.items():
            png(svg_doc(fg + badge_paths(env), VISIBLE, mask="rounded"), px, res / f"mipmap-{density}/ic_launcher.png")
            png(svg_doc(fg + badge_paths(env), VISIBLE, mask="circle"), px, res / f"mipmap-{density}/ic_launcher_round.png")


def write_ios(env, fg, out):
    crop = BRAND["storeCrop"]
    icon_set = out / "ios/AppIcon.appiconset"
    png(svg_doc(fg + badge_paths(env), crop), 1024, icon_set / "AppIcon-1024.png", alpha=False)
    png(svg_doc(fg + badge_paths(env), crop, background=BRAND["darkBackground"]), 1024,
        icon_set / "AppIcon-1024-dark.png", alpha=False)
    png(svg_doc(white(fg) + badge_paths(env), crop, background="#000000"), 1024,
        icon_set / "AppIcon-1024-tinted.png", alpha=False, grayscale=True)
    image = {"idiom": "universal", "platform": "ios", "size": "1024x1024"}
    contents = {
        "images": [
            {**image, "filename": "AppIcon-1024.png"},
            {**image, "filename": "AppIcon-1024-dark.png",
             "appearances": [{"appearance": "luminosity", "value": "dark"}]},
            {**image, "filename": "AppIcon-1024-tinted.png",
             "appearances": [{"appearance": "luminosity", "value": "tinted"}]},
        ],
        "info": {"author": "xcode", "version": 1},
    }
    (icon_set / "Contents.json").write_text(json.dumps(contents, indent=2) + "\n")


def write_ios_launch_screen(fg, out):
    """LaunchLogo (mark only, transparent) + LaunchBackground color for Info.plist UILaunchScreen."""
    logo_set, color_set = out / "ios/LaunchLogo.imageset", out / "ios/LaunchBackground.colorset"
    images = []
    for scale in (1, 2, 3):
        name = f"LaunchLogo@{scale}x.png"
        png(svg_doc(fg, 48, background="none"), 120 * scale, logo_set / name)    # 120 pt logo
        images.append({"idiom": "universal", "filename": name, "scale": f"{scale}x"})
    info = {"author": "xcode", "version": 1}
    (logo_set / "Contents.json").write_text(json.dumps({"images": images, "info": info}, indent=2) + "\n")
    red, green, blue = (f"0x{BRAND['background']['start'][i:i + 2].upper()}" for i in (1, 3, 5))
    color = {"color-space": "srgb", "components": {"red": red, "green": green, "blue": blue, "alpha": "1.000"}}
    color_set.mkdir(parents=True, exist_ok=True)
    (color_set / "Contents.json").write_text(
        json.dumps({"colors": [{"idiom": "universal", "color": color}], "info": info}, indent=2) + "\n")


def write_store_and_web(env, fg, out):
    crop = BRAND["storeCrop"]
    png(svg_doc(fg + badge_paths(env), crop), 512, out / "store/play-icon-512.png")   # 32-bit PNG, Play masks it
    for name, px in {"favicon-32.png": 32, "icon-192.png": 192, "icon-512.png": 512,
                     "apple-touch-icon.png": 180}.items():
        png(svg_doc(fg + badge_paths(env), crop), px, out / f"web/{name}", alpha=name != "apple-touch-icon.png")


def write_in_app_logo(fg):
    """core/ui logo for splash, About, drawer header: rounded tile + mark, solid color (no aapt)."""
    o = (CANVAS - VISIBLE) / 2
    tile = {"d": f"M{o + 13:g},{o:g}h{VISIBLE - 26}a13,13 0,0 1,13 13v{VISIBLE - 26}a13,13 0,0 1,-13 13"
                 f"h-{VISIBLE - 26}a13,13 0,0 1,-13 -13v-{VISIBLE - 26}a13,13 0,0 1,13 -13z",
            "fill": BRAND["background"]["start"], "opacity": 1.0, "evenOdd": False}
    xml = vector_xml([tile] + fg, size=VISIBLE)
    xml = xml.replace("\n    <path", f'\n    <group android:translateX="-{o:g}" android:translateY="-{o:g}">\n    <path', 1)
    xml = xml.replace("\n</vector>", "\n    </group>\n</vector>")
    IN_APP_LOGO.parent.mkdir(parents=True, exist_ok=True)
    IN_APP_LOGO.write_text(xml)


def main():
    fg = read_mark(ROOT / BRAND["foreground"])
    for path in fg:
        if not re.fullmatch(r"#[0-9A-Fa-f]{6}", path["fill"]):
            raise SystemExit(f"fill must be #RRGGBB, got {path['fill']}")
    shutil.rmtree(OUT, ignore_errors=True)
    for env in ("prod", "uat"):
        out = OUT / env
        write_android(env, fg, out)
        write_ios(env, fg, out)
        write_ios_launch_screen(fg, out)
        write_store_and_web(env, fg, out)
    write_in_app_logo(fg)
    print(f"Icons written to {OUT.relative_to(ROOT)}/{{prod,uat}} and {IN_APP_LOGO.relative_to(ROOT)}")


if __name__ == "__main__":
    main()
```

Rules for the script:
- Never hand-edit anything under `branding/generated/` or `app_logo.xml`. Change
  `mark.svg` or `brand.json` and run the script again.
- Commit `branding/generated/` (it is small) so builds and CI don't need cairo.
- The UAT badge is drawn as paths (pill + blocky "UAT" letters), so it needs no
  font and appears on every UAT icon, including the themed/monochrome one.
  PROD icons and the in-app logo never have it.

## 6. Wiring per environment (extends `kmp-environments`)

Amper has no product flavors, so the active environment's icon is **copied**
into the app by `scripts/use_env.py`, exactly like `GoogleService-Info.plist`.
Add this to `use_env.py` and call it from `main()` after the env is chosen:

```python
BRANDING = ROOT / "branding/generated"
ANDROID_RES = ROOT / "app/androidApp/res"
IOS_ASSETS = ROOT / "app/iosApp/src/Assets.xcassets"          # the catalog found in section 2

def copy_icons(env_name: str) -> None:
    """Puts the UAT or PROD icon set into the Android and iOS apps."""
    source = BRANDING / env_name.lower()
    if not source.exists():
        sys.exit("Icons missing: run python3 scripts/branding/make_icons.py")
    shutil.copytree(source / "android/res", ANDROID_RES, dirs_exist_ok=True)
    for asset in ("AppIcon.appiconset", "LaunchLogo.imageset", "LaunchBackground.colorset"):
        shutil.rmtree(IOS_ASSETS / asset, ignore_errors=True)
        shutil.copytree(source / "ios" / asset, IOS_ASSETS / asset)

# in main(), next to the plist copy:
copy_icons(props["ENV_NAME"])
```

**Android (`app/androidApp`)**
- Delete the template's old launcher files first (`mipmap-*/ic_launcher*.webp`/
  `.png`, old `drawable/ic_launcher_*`). Two files with the same resource name
  and different extensions fail the build.
- `AndroidManifest.xml`:
  `<application android:icon="@mipmap/ic_launcher" android:roundIcon="@mipmap/ic_launcher_round" …>`
- The launcher label "(UAT)" already comes from `kmp-environments`. The badge is
  the visual twin of that label.

**iOS (`app/iosApp`)**

## 7. Logo lockup and wordmark (optional)

For the web landing page, About screen header, press kit or feature graphic, a
**lockup** is the mark plus the app name. The name is turned into paths from the
app's own OFL font, so it renders the same everywhere without shipping the font:

```python
# pip install fonttools
from fontTools.pens.svgPathPen import SVGPathPen
from fontTools.pens.transformPen import TransformPen
from fontTools.ttLib import TTFont

def text_path(font_path, text, size, x, baseline):
    """SVG path data for `text`, plus the x where it ends. Latin only: no kerning or shaping."""
    font = TTFont(font_path)
    glyph_set, cmap = font.getGlyphSet(), font.getBestCmap()
    scale = size / font["head"].unitsPerEm
    pen = SVGPathPen(glyph_set)
    for char in text:
        glyph = glyph_set[cmap[ord(char)]]
        glyph.draw(TransformPen(pen, (scale, 0, 0, -scale, x, baseline)))
        x += glyph.width * scale
    return pen.getCommands(), x
```
- Save it as `branding/logo/lockup.svg`: mark on the left, name on the right,
  vertically centered, with a gap of about 1/4 of the mark's height. Make a
  light and a dark (white text) version.
- For Bangla or other complex scripts, this simple pen has no shaping and breaks
  conjuncts. Use the mark alone, or render the name in the UI with the real font.

## 8. Splash / launch screen

Keep it to brand color + mark: no text, no spinner, no ads.

**Android 12+** shows the adaptive icon on a background color. Use
`androidx.core:core-splashscreen` so older versions match:

<style name="Theme.App.Starting" parent="Theme.SplashScreen">

the badge here too, which is fine for testers.

<key>UILaunchScreen</key>

## 9. Brand backgrounds, images and in-app icons

Follow `compose-multiplatform-ui` 2.0.2 for *how* (vector XML icons, `ImageVector`
illustrations with theme colors, `Canvas` backgrounds). Brand-specific additions:
- **Reuse the mark's shapes as the motif.** Backgrounds, empty states and
  onboarding art use the same corner radius, the same tile/curve language and
  the theme colors from the same seed. That makes them look like one family
  with the icon.
- **Brand pattern background** (login, onboarding, drawer header):
  ```kotlin
  // core/ui/.../customUI/background/BrandPatternBackground.kt
  @Composable
  fun BrandPatternBackground(modifier: Modifier = Modifier) {
      val colors = MaterialTheme.colorScheme
      Canvas(modifier.fillMaxSize()) {
          drawRect(Brush.linearGradient(listOf(colors.primary, colors.primaryContainer)))
          val tile = size.minDimension * 0.22f
          val corner = CornerRadius(tile * 0.18f)
          listOf(0.72f to -0.04f, 0.86f to 0.10f, -0.06f to 0.78f).forEach { (fx, fy) ->
              drawRoundRect(colors.onPrimary.copy(alpha = 0.08f), Offset(size.width * fx, size.height * fy),
                            Size(tile, tile), corner)
          }
      }
  }
  ```
  Text on it uses `onPrimary` and stays in the center, away from the tiles.
- **Larger images** (onboarding hero, empty states) are `ImageVector`
  illustrations in `core/ui/.../customUI/illustration/`. **Photos** are never
  taken from the web. Use a tonal placeholder and ask the user for their own photo.
- **In-app icons** stay Material Symbols in one style (Rounded or Outlined,
  app-wide). Draw a custom `ic_<name>.xml` only when no Material Symbol fits.
- **Desktop window icon:** `Window(icon = painterResource(Resources.Drawable.AppLogo), …)`.
- **Web (wasm) app:** copy `branding/generated/prod/web/*` next to the web app's
  `index.html` and add
  `<link rel="icon" href="favicon-32.png">`,
  `<link rel="apple-touch-icon" href="apple-touch-icon.png">`, and the 192/512
  icons in the web manifest, if there is one.
- Register any new drawable in `Resources.Drawable`. Features never keep their own
  logo copy.
